**Insect Vision: Ocelli Function**

* Most insects possess three frontal eyes called **ocelli**, each with a single lens similar to the vertebrate eye.
* In some flying insects (locusts and dragonflies), **ocelli** function as horizon detectors for visual stabilization.

**Navigation Using Polarized Light**

* Desert ants (**Cataglyphis**) use **ocelli** to read compass information from polarized light in the blue sky.
* When both sun and landmarks are obscured, **ocelli** guide the ant back home using polarized light patterns.
